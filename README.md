## Selected Projects

### 🌸 Iris Logistic Regression — From Scratch

Implemented logistic regression using **NumPy**, building the core mathematics rather than relying on a machine-learning library.

**Sigmoid → Cost Function → Gradient Descent → Predictions → Evaluation**

> Focus: ML fundamentals · Mathematics · NumPy · Optimization

---

### 🌊 OceanEmbed — Subsurface Ocean Temperature Reconstruction

A deep-learning framework developed for Smart India Hackathon 2026, combining ocean-surface observations, CNN-based reconstruction, and interactive scientific visualisation to explore subsurface temperature across the North Indian Ocean.

Tech: Python · TensorFlow · CNNs · FastAPI · React · Vite · xarray

Focus: Deep Learning · Scientific ML · Geospatial Data · API Integration · Data Visualisation

---

### 📚 NCERT AI Tutor

An AI-powered educational assistant using **Retrieval-Augmented Generation (RAG)** to answer questions from NCERT content.

> Focus: RAG · Embeddings · LLMs · Retrieval
